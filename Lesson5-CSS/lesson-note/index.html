HTML vs. CSS: The House Analogy

HTML = Structure

HTML gives a webpage its structure. It tells the browser: "This is a heading, this is a paragraph, this is an image."

Think about a house: HTML represents the walls, the doors, and the layout of the rooms.

CSS = Presentation

CSS controls how that structure looks. It tells the browser: "Make this heading blue and large."

Think about a house: CSS represents the paint on the walls, the furniture, and the beautiful decorations.

What is CSS?

  • CSS stands for Cascading Style Sheets.
  • It is the technology used to control the visual presentation of webpages.
  • With CSS, we can easily control:
    • Text Colors & Backgrounds
    • Fonts & Text Sizes
    • Spacing & Layout
    • Borders & Shadows

Basic CSS Syntax

Every piece of CSS you write follows this exact same pattern:

h1 { color: blue; }

Selector
(What to style)

Property
(What to change)

Value
(The new style)

Don't forget the semicolon (;) at the end of every declaration!

Ways of Adding CSS

1. Inline CSS

Written directly inside an HTML element using the style attribute.

<h1 style="color: blue;">
Welcome
</h1>

❌ Hard to maintain.

2. Internal CSS

Written inside a <style> element in the HTML <head>.

<style>
  h1 { color: blue; }
</style>

⚠️ Good for small tests.

3. External CSS

A completely separate .css file connected via the <link> tag.

<link rel="stylesheet" href="style.css">

✅ Professional Standard!

CSS Selectors (How to target elements)

Element Selector

Targets EVERY element of that type on the page.

p {
  color: green;
}

Class Selector (.)

Targets elements with a specific class. Reusable!

.highlight {
  color: red;
}

ID Selector (#)

Targets a single, unique element on the page.

#title {
  color: purple;
}

Pro Tip: You can group selectors with commas! e.g., h1, h2, p { color: blue; }

Colors in CSS

Text vs Background

color changes text. background-color changes the element's box.

p {
  color: white;
  background-color: black;
}

Color Formats

Named: red, blue, white
HEX: #2563eb (Red/Green/Blue hex mix)
RGB: rgb(37, 99, 235)
RGBA: rgba(0, 0, 0, 0.5) (Adds transparency/opacity at the end!)

Styling Backgrounds

  • Background Image:
    background-image: url("images/bg.jpg");
    (Remember: The file path is relative to where your CSS file is saved!)
  • Background Repeat:
    background-repeat: no-repeat;
    Stops the image from tiling over and over.
  • Background Position:
    background-position: center;
  • Background Size:
    background-size: cover;
    Forces the image to cover the entire space while keeping its proportions.

Comments & Browser Dev Tools

CSS Comments

Comments allow developers to leave notes inside their code. They are completely ignored by the browser.

Use them to explain sections, leave reminders, or temporarily disable a line of CSS.

/* --- Navigation Styles --- */
nav {
  background-color: black;
}

Developer Tools

Professional developers don't just guess; they inspect! Right-Click -> Inspect (or F12)

  • Elements Panel: See the HTML structure.
  • Styles Panel: See active CSS rules.
Try it: You can edit colors or sizes right in the browser! (Note: Changes are temporary and disappear on refresh).

Common CSS Mistakes

Missing The Link

If you don't add the <link rel="stylesheet"> to your HTML head, or if the file path is wrong, your CSS simply won't load.

Forgetting Symbols

Forgetting the dot (.) before a class name, or the hash (#) before an ID name in your CSS file.

Missing Semicolons

If you forget the semicolon ; at the end of a line, the browser gets confused and the next rule might break.
